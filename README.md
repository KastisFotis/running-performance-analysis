# Running Performance Analysis

A data analysis project exploring my running training data, with a focus on training volume, aerobic efficiency, heart rate, and performance progression.

## Project Goals

The main objectives of this project are to:

- Analyze weekly training volume
- Study the relationship between pace and heart rate
- Track aerobic efficiency over time
- Compare different types of training sessions
- Visualize performance trends

## Dataset

The dataset will contain information from running training sessions, including:

- Date
- Distance
- Average pace
- Average heart rate
- Elevation gain
- Workout type

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
